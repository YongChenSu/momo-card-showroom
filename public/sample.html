momo-cards 嵌入範例

這個頁面只載入 embed/momo-cards.js 一支 script，然後以 HTML 屬性宣告卡片。 頁面刻意設定了 article, img { border: 3px dashed red !important }，卡片不受影響——樣式隔離在 Shadow DOM 內。

1. 宣告式使用

<momo-product-card variant="grid" product='{...}'>：商品資料是 JSON 字串，由元件驗證。第三張與第一張是同一筆商品資料，只把 variant 換成 compact。

2. 單張卡片覆寫設定（config 屬性）

優先序：config 屬性 > showroom 儲存的設定 > 預設值。下面這張把價格改為藍色、隱藏評分與銷量、標題限 1 行。

3. 容錯（打開 DevTools console 看 [momo-cards] 訊息）

  • 第一張：含未註冊的角標 anniversary 與格式錯誤的 mo-points——壞角標被跳過，其餘照常顯示
  • 第二張：variant="unknown"——退回 grid
  • 第三張：product 不是合法 JSON——不渲染，但不影響頁面其他部分

4. 以 JavaScript 建立 / 共用設定

卡片也可以用 document.createElement 動態建立。window.MomoCards.configStore 是同一份設定 store： 更新後頁面上所有同 variant 的卡片即時重繪，並寫入 localStorage（與同網域的 showroom 共用，重新整理後保留）。

5. 自訂角標（MomoCards.registerBadge）

宿主頁可註冊自己的角標，只需提供 type、slot 與回傳 { label, color } 的 view 函式——不需要 React。卡片本體不用改。

  • 第一張：double-11 在 <head> 就已註冊，一開始即顯示於左上角
  • 第二張：flash-sale 尚未註冊，先被跳過並回報；按下按鈕後才註冊，已渲染的卡片即時補上角標
  • 第三個按鈕：註冊與內建重複的 ad——被拒絕並回報，內建角標不會被覆蓋
